COMPARATEUR D'ADRESSES - V6.0 - DEMARRAGE RAPIDE

1) Cloner le depot et entrer dans le dossier

   git clone https://github.com/RedakArraid/jin-adresse-model.git
   cd jin-adresse-model


2) Demarrer l'API et l'interface

   docker compose up --build -d


3) Ouvrir les services

   Interface :
   http://localhost:8501

   API Swagger :
   http://localhost:8000/docs

   Healthcheck :
   http://localhost:8000/health


4) Essayer le moteur sans BAN

   Le moteur fonctionne directement en mode structurel V6.0.

   Il applique :
   - canonicalisation de chaque adresse ;
   - preuves par champ ;
   - modele logistique local pour la similarite ;
   - moteur de decision separe ;
   - politique centralisee dans app/model_config.json.


5) Optionnel - importer la BAN locale

   Un departement :

   docker compose run --rm ban-loader --departments 13

   Plusieurs departements :

   docker compose run --rm ban-loader --departments 13 75 69 93

   Le scoring reste ensuite local dans SQLite.


6) Verifier l'etat de la BAN

   curl http://localhost:8000/ban/status


7) Tester l'API

   curl -X POST http://localhost:8000/score \
     -H "Content-Type: application/json" \
     -d '{
       "address_a": "187 bld de pontoise 75015 paris",
       "address_b": "187 boulevard de pontoise 75015 paris",
       "use_ban": true
     }'


8) Lancer les tests

   python -m unittest discover -s tests -v

   Le corpus de non-regression est :
   tests/corpus_decisions.json


9) Voir les logs

   docker compose logs -f api ui


10) Arreter

   docker compose down

   Pour supprimer egalement le volume BAN :

   docker compose down -v


DECISIONS

MEME_ADRESSE
A_CONTROLER
DIFFERENTE

Le seuil de match automatique est 95.
Les noms de voie proches mais non identiques sont plafonnes a 89 et restent A_CONTROLER.
